# 🎓 School Management System

A comprehensive School Management System built with **ASP.NET Core MVC**, **Entity Framework Core**, and **SQLite**.

## ✨ Features

- 👥 **User Management**: Students, Teachers, Admins with role-based access.
- 📚 **Courses**: Manage courses, departments, and course-teacher assignments.
- 📝 **Enrollments**: Students can enroll in open courses.
- 📊 **Grades**: Automatic grade calculation based on Assignments, Midterms, Finals, and Quizzes.
- 📅 **Attendance**: Track student attendance per course.
- 📹 **Lessons**: Upload video lessons (from device or YouTube).
- ❓ **Quizzes**: Create quizzes with MCQ questions, auto-grading, and timer.
- 📈 **Dashboards**: Separate dashboards for Admin, Teacher, and Student.
